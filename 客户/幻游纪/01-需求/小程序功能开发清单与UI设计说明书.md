小程序功能开发清单与UI设计说明书
产品名称（暂定）：幻游纪 · AI视频换脸文旅电商小程序 文档版本：V1.0 文档类型：功能开发清单（PRD）+ UI设计说明 适用端：用户端微信小程序 / 运营端Web后台 / 商家端Web后台

1. 项目概述
1.1 产品定位与核心价值
本产品是一款以「AI视频人物替换（换脸）」为核心玩法、以「文旅内容」为流量场景、以「电商」为变现闭环的微信小程序。
* 核心玩法：用户上传一张本人或他人的人脸照片，选择热门影视剧、综艺节目、明星片段或文旅宣传视频作为样板模板，由AI将视频中的人物面部替换为用户上传的人脸，生成一段”我就是主角”的个性化短视频，可下载、可分享至微信会话/朋友圈。
* 文旅场景：平台与目的地城市内容结合，提供城市必备打卡视频、景点介绍、旅游攻略、美食地图等内容型视频模板，让用户”穿越”到景区古装、城市宣传片之中，形成”内容种草—视频生成—社交裂变—目的地消费”的文旅传播链路。
* 电商变现：在小程序内嵌商城，围绕”美食、穿戴产品、日用周边、定制”四大类目销售目的地特色商品与平台定制周边（如AI换装写真周边、文创定制），并通过城市定位实现”本地内容 + 本地商品”的精准匹配，完成商业闭环。
核心价值一句话：用最低门槛的AI换脸玩法制造快乐与传播，用文旅内容承接流量，用电商完成变现。

5. 通用与底层能力
5.1 账号体系
* C端用户：微信一键授权登录（获取OpenID/UnionID），头像昵称授权遵循微信最新规范（头像昵称填写能力）；不强制手机号，下单时可选择授权手机号用于物流联系。
* 运营/商家账号：独立账号密码体系 + 图形验证码 + 可选二次验证；基于RBAC模型的角色权限控制；平台管理员拥有最高权限。
* 商家账号与店铺强绑定，仅可见本店数据；运营账号按角色划分可见菜单与操作。
5.2 AI视频生成服务
* 生成队列：用户提交的换脸任务进入统一消息队列，按提交顺序+优先级调度；队列长度与预计等待时长实时反馈给用户端。
* 算力调度：GPU算力资源池化，支持弹性扩缩容；高峰期排队降级策略（提示预计等待时间、引导订阅完成通知后离开）。
* 失败重试：生成失败自动重试（最多2次），仍失败则标记失败并通知用户，支持一键重新生成且不重复扣减额度。
* 内容安全审核：三级防线——①上传照片机器审核（人脸质量、涉政涉黄、名人脸库比对）；②样板视频上架前人工+机器审核；③生成结果出仓前安全复核（涉政/涉黄/暴恐/侵权拦截），命中即拦截并记录。严格遵守《互联网信息服务深度合成管理规定》，生成视频添加”AI合成”显著标识。
5.3 存储策略
* 样板视频：对象存储长期保存，CDN加速分发，多码率转码适配不同网络环境。
* 用户人脸照片：处理完成后24小时内删除原图，仅保留特征中间数据用于当次任务，不向第三方提供。
* 生成视频：写入临时存储并设置72小时TTL，到期自动物理删除，不可恢复；到期前6小时触发订阅消息提醒；用户主动删除即时生效。
* 存储生命周期由对象存储生命周期规则 + 定时清理任务双重保障，每日巡检清理遗漏文件。
5.4 支付与订单
* 接入微信支付（小程序支付），平台持商户号统一收款。
* 分账：平台与商家按约定比例分账，采用微信支付分账能力，订单确认收货后T+N结算至商家。
* 订单状态机：待付款→待发货→待收货→已完成；待付款30分钟未支付自动关闭；售后状态独立流转。
* 退款原路退回，退款成功后同步更新分账。

7. UI设计说明
7.1 设计语言与风格定位
整体风格定位为「年轻 · 国潮文旅 · 温暖质感」：
* 面向18-35岁爱分享、爱旅行的年轻用户，视觉语言轻松、有网感；
* 融入国潮文旅元素：在图标纹样、插画、节日皮肤中使用中式纹样（回纹、云纹）、印章式标签、纸质肌理背景，营造”穿越进影视与古城”的代入感；
* 色彩采用低饱和度暖色调体系，避免高饱和大面积背景与蓝紫科技感渐变，让内容（视频封面）成为视觉主角；
* 圆角卡片 + 轻投影 + 大留白的版式，保证信息层级清晰、操作路径短。

7.5 核心组件规范
* 导航栏：米白底色/毛玻璃效果，左侧返回、居中标题、右侧可放置城市定位胶囊（文旅/商城页）。
* 底部Tab栏：四Tab（首页/文旅/商城/我的），图标采用线性风格 + 选中态填充主色朱砂红，选中项附带短横线指示器；文旅Tab图标融入地标（塔/城楼）元素。
* 搜索框：圆角全圆（999rpx）浅暖灰底（#F3EEE7），左侧放大镜图标，占位符弱文字色；首页/各品类页均常驻顶部。
* 视频卡片：封面（3:4竖版）+ 标题（最多2行省略）+ 生成次数 + 标签（城市/性别角标）；封面右上角可配置”热”印章角标。
* 商品卡片：1:1方图 + 商品名（2行）+ 价格（朱砂红，¥符号小字号）+ 销量 + 城市标签。
* 筛选器：胶囊式横滑筛选条，选中态为主色描边+浅主色底；排序类（生成量递增/递减）带上下箭头图标切换。
* 按钮：主按钮（朱砂红实底白字，高度88rpx，圆角44rpx）、次按钮（主色描边白底）、文字按钮、禁用态（暖灰底）。
* 弹窗：居中圆角弹窗（圆角24rpx）与底部动作面板（顶部圆角24rpx）两种形态；遮罩 rgba(0,0,0,0.5)。
* Toast：黑底白字（80%透明度）居中轻提示，2秒自动消失；成功/失败带图标。
* 空状态：国潮插画（如空白卷轴/空行囊）+ 引导文案 + 行动按钮（如”去逛逛”）。
* 加载骨架屏：列表加载使用骨架屏（卡片轮廓呼吸动画），避免白屏。
7.6 交互说明
* 下拉刷新：首页/文旅/商城列表支持下拉刷新，刷新动效为品牌印章旋转动画。
* 上滑加载：滚动触底自动加载下一页，加载中显示”正在加载…“，无更多显示”到底啦～“。
* 城市定位授权流程：首次进入文旅/商城页 → 弹出自定义说明弹窗（说明定位用于推荐本地内容）→ 用户同意后调起微信定位授权 → 授权失败/拒绝则降级为默认热门城市，并保留右上角手动切换入口；拒绝后再次点击定位时引导至设置页开启。
* 生成进度反馈：生成中页展示环形进度 + 排队位次 + 预计剩余时间；支持”完成后通知我”订阅按钮，用户可离开页面，订阅消息召回。
* 72h倒计时样式：生成视频卡片右下角常驻倒计时胶囊（白底弱文字色：剩 47:12:30）；剩余<6小时胶囊变为警示橙底白字并带时钟图标；预览页顶部展示保留期提示横幅”视频将于 XX月XX日 XX:XX 后删除，请及时下载”。
7.7 各页面UI描述
首页：顶部为米白底自定义导航（左侧品牌字标，右侧无操作）；其下为全圆角搜索框；再下为横向分类Tab（推荐/电影/电视剧/综艺/明星，选中项朱砂红加粗 + 下划线）；Tab下方为运营Banner轮播（圆角16rpx）；主体为双列视频瀑布流，卡片白底圆角，封面3:4，卡片底部依次为标题、生成量与标签行。
文旅页：导航栏左侧为页面标题”文旅”，右侧为城市定位胶囊（定位图标+城市名）；下方为顶部四栏目菜单（城市必备视频/景点介绍/旅游攻略/美食地图，图标+文字横排或两行两行宫格）；再下为筛选器横滑条（全部/文旅/博物馆｜生成量递减▾｜男角色/女角色）；主体为当前城市热门视频双列瀑布流，卡片带城市角标与性别角标。
商城页：结构与文旅页对仗——右上角城市定位胶囊；顶部分类菜单（美食/穿戴产品/日用周边/定制）；Banner活动位；双列商品卡片流（1:1图+名称+价格+销量）。
我的页：顶部为用户信息卡（头像圆形、昵称、“开通会员/登录”引导位）；其下为”我的生成视频”横滑预览条（缩略图+倒计时角标，点击查看全部）；再下为订单信息栏（待付款/待发货/待收货/已完成/售后五宫格图标入口）；底部为功能列表（收藏、地址、客服、设置，右箭头列表项）。
视频替换生成流程页：模板详情为沉浸式全屏视频播放 + 底部毛玻璃操作栏（模板信息 + “立即换脸”主按钮）；上传照片页为居中人像框虚线框 + 相册/拍摄双按钮 + 拍摄指引（正脸、光线、无遮挡三图标提示）；生成中页为环形进度动画 + 趣味文案轮播（“正在为你穿越剧中…”）+ 订阅通知按钮；预览页全屏播放成片，底部操作栏（重新生成/保存相册/分享），顶部72h保留提示横幅。
运营端后台：左侧深色（黛青 #4A5B5C）导航 + 顶部面包屑与账号区 + 右侧内容区；数据看板为卡片式指标栅格 + 趋势折线图 + 排行榜表格；视频管理为筛选条 + 数据表格（封面缩略、标题、分类、城市、状态、操作列）+ 上传弹窗。
商家端后台：与运营端同框架保证一致性，导航精简为数据概览/商品/订单/店铺设置；商品列表为图文表格 + 批量操作栏；订单页为状态Tab + 表格 + 发货/售后弹窗。

9. 开发优先级与里程碑建议
9.1 MVP版本范围（P0功能）
MVP以「换脸核心链路跑通 + 基础电商交易闭环」为目标，包含：
* 用户端：导播页（含隐私协议）、首页（分类/搜索/视频流/详情）、文旅页（城市定位/四栏目/筛选器/视频流）、商城页（分类/商品流/详情/下单支付）、我的（生成视频72h管理下载、订单）、完整生成流程；
* 运营端：样板视频上传-转码-审核-上下架全链路、分类标签城市管理、推荐位与排序干预、核心数据看板、用户与权限管理、商家入驻审核；
* 商家端：入驻、商品发布审核上下架、订单发货与售后处理、结算对账；
* 底层：微信登录、AI生成队列与安全审核、72h TTL存储、微信支付与分账、订阅消息。
